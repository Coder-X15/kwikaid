# First Aid Companion

Create for me a basic first-aid helper webapp that complies with the following use cases:
1. The authenticated user can take a photo of an injury and send it to the agent, which then formulates the steps of responding to the same, created to navigate step-wise. Once the instructions have been completely carried out, the users can follow-up with related other matters in the same situation, regarding ensuring that a sling has been tied right, etc.
2. The agent shoud be able to place a call given the severity of the injury.
3. The app should keep track of incidents and whether calls were made, as well as the symptoms seen.
Tese features should be implemented as dummy ones for now. Also, the app's design should followa general hospital colour aesthetic. Dummy login credentials: username = "test", password = "test"
